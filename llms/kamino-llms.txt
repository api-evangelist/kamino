# Kamino Public API

> HTTPS endpoints for data, analytics, and unsigned transactions on Solana. Language-agnostic.

Base URL: https://api.kamino.finance

## Capabilities

- Query real-time and historical data for Kamino Finance products on Solana
- Track user positions, rewards, and portfolio values
- Retrieve oracle prices, staking yields, epoch data, and protocol metrics
- Build unsigned transactions for lending, borrowing, swaps, and liquidity operations (must be signed client-side)
- All endpoints are language-agnostic HTTP/JSON

## Products

- Kamino Lend: supply assets to earn yield across lending markets
- Borrow: borrow against collateral on Kamino lending markets
- Swap: token swap aggregation
- Multiply: leveraged yield strategies through looping
- Liquidity: automated liquidity vaults for concentrated liquidity DEXs
- Leverage: leveraged trading positions
- User Holdings: user positions, rewards, and portfolio tracking
- Data & Utilities: staking yields, oracle prices, epoch data, protocol metrics
